# شجرة العائلة — دليل التشغيل

أداة ويب لبناء شجرة عائلة تفاعلية، يقترح فيها أفراد العائلة إضافات جديدة وتخضع لمراجعة المسؤول (الأدمن) قبل ظهورها.

## الملفات
```
family-tree/
├── index.html          الصفحة العامة (عرض الشجرة + اقتراح إضافات)
├── admin.html           لوحة تحكم الأدمن (المراجعة + الإدارة)
├── css/style.css
├── js/
│   ├── firebase-config.js   ← تعبّي فيه بيانات مشروعك
│   ├── firebase-init.js
│   ├── app.js
│   └── admin.js
├── firestore.rules      قواعد أمان قاعدة البيانات
└── storage.rules        قواعد أمان تخزين الصور
```

## خطوة 1 — إنشاء مشروع Firebase
1. روح إلى https://console.firebase.google.com وسوّ مشروع جديد (مجاني، خطة Spark تكفي).
2. من القائمة الجانبية: **Build → Firestore Database** → أنشئ قاعدة بيانات (اختر أي موقع قريب منك، وابدأ بوضع "production mode").
3. من القائمة الجانبية: **Build → Storage** → فعّلها (تُستخدم لتخزين الصور).
4. من القائمة الجانبية: **Build → Authentication** → تبويب **Sign-in method** → فعّل **Email/Password**.
5. في نفس صفحة Authentication → تبويب **Users** → **Add user** → أدخل إيميلك وكلمة سر قوية. هذا الحساب هو حساب الأدمن اللي بتسجّل فيه دخول من `admin.html`.
6. ارجع لإعدادات المشروع (أيقونة ⚙️ بجانب "Project Overview") → **Project settings** → انزل لقسم "Your apps" → اضغط أيقونة الويب `</>` → سمّ التطبيق أي اسم → هيسجّل لك كائن `firebaseConfig`.
7. انسخ القيم وحطها في ملف `js/firebase-config.js` بدل النصوص `PASTE_...`.

## خطوة 2 — رفع قواعد الأمان
أسهل طريقة بدون تثبيت أي أدوات:
- **Firestore**: من الكونسول → Firestore Database → تبويب **Rules** → الصق محتوى ملف `firestore.rules` → Publish.
- **Storage**: من الكونسول → Storage → تبويب **Rules** → الصق محتوى ملف `storage.rules` → Publish.

(لو تفضّل، تقدر تستخدم Firebase CLI: `firebase deploy --only firestore:rules,storage:rules`)

## خطوة 3 — رفع المشروع على GitHub Pages
1. سوّ مستودع (repository) جديد على GitHub وارفع جميع ملفات هذا المجلد فيه.
2. من إعدادات المستودع **Settings → Pages** → اختر الفرع (branch) اللي فيه الملفات (غالباً `main`) والمجلد الجذر `/ (root)` → Save.
3. بعد دقيقة أو دقيقتين بيعطيك GitHub رابط الموقع (مثال: `https://username.github.io/family-tree/`).

> ملاحظة أمان: ملف `firebase-config.js` يحتوي مفاتيح عامة (publishable) مخصصة للاستخدام في المتصفح، مو أسرار — لكن الحماية الحقيقية تجيك من قواعد `firestore.rules` و `storage.rules` نفسها، فتأكد إنك رفعتها بالظبط زي ما هي.

## تفعيل الصور لاحقاً
الصور معطّلة مؤقتاً في هذه النسخة لأن Firebase Storage يتطلب خطة **Blaze** (الدفع حسب الاستخدام — مجانية ضمن حدود سخية شهرياً). متى ما رقّيت مشروعك للخطة:
1. من الكونسول: **Build → Storage → Get started** لتفعيل الخدمة.
2. الصق قواعد `storage.rules` في تبويب Rules (كما في خطوة 2 أعلاه).
3. في `index.html` و `admin.html`: احذف `style="display:none;"` من العنصر `id="photoFieldWrap"`، واحذف سطر `<p ... id="photoDisabledNote">...</p>` المجاور له.
4. ارفع التحديث على GitHub — وبكذا تكون الصور شغالة.

## خطوة 4 — إضافة أول بيانات (الجد الأول)
1. افتح `admin.html` من الموقع وسجّل دخول بحساب الأدمن اللي سويته في خطوة 1.
2. روح لتبويب **"إضافة فرد مباشرة"** واختر "بدون (جذر الشجرة)" كأب/أم، وأضف الجد الأول.
3. من نفس التبويب أضف بقية بياناتك الأولية الجاهزة (كل شخص تحدد له "الأب/الأم" من القائمة).
4. بعدها روح لـ `index.html` وشوف الشجرة تكبر تلقائياً.

## كيف تشتغل الأداة
- **أي فرد من العائلة** يفتح `index.html`، يعبّي بياناته (اسم رباعي، إيميل، جوال) مرة وحدة (تُحفظ في متصفحه)، يضغط على أي اسم بالشجرة، ويضيف له ابن/ابنة مع صورة اختيارية.
- الإضافة **ما تظهر فوراً** — تروح لقائمة "طلبات الإضافة" في `admin.html` بانتظار قرار الأدمن (قبول/رفض).
- **الأدمن فقط** يقدر يعدّل أو يحذف بيانات موجودة سابقاً في الشجرة، من تبويب "إدارة الشجرة".
- لو عندك أكثر من أدمن، سوّ لكل واحد "Add user" في خطوة Authentication، وكلهم يقدرون يسجلون دخول بنفس `admin.html`.

## تخصيص الشكل
- عنوان الشجرة يتغيّر من داخل `index.html` (عنصر `<h1 id="familyTitle">`).
- الألوان والخطوط كلها في `css/style.css` أعلى الملف تحت `:root`.
